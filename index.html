Built Before Frameworks Did It For You

Selected Projects

College-era Java. No Spring Boot magic, no cloud scaffolding — just JDBC, Sockets, Swing, and Tomcat. Each project broke something important and taught me why it broke. That's still how I learn.

Desktop · Java · JDBC · MySQL
Library Management System
Multi-user Swing desktop app for the college library — book inventory, member records, checkout/return workflows, due date tracking, and fine calculation. The concurrent checkout problem forced me into JDBC transactions for the first time: two students hitting "borrow" on the last available copy at the same instant.
My first version gave both students a success response. Only one copy existed. A BEGIN TRANSACTION and a row-level lock fixed it. That day I understood what a database actually protects you from.
Java · Swing · JDBC · MySQL · MVC Pattern
Networking · Java Sockets · Threading
Multi-threaded LAN Chat Server
TCP socket server where every connected client gets a dedicated thread — broadcast messaging across the college computer lab. Built to understand concurrency from first principles: one thread per connection, shared message queue, and a broadcaster that writes to all active sessions simultaneously.
I was suppressing a NullPointerException in the message handler for two weeks before I noticed it was silently dropping every 8th message. Swallowing exceptions is how you create ghost bugs. Never again.
Java · TCP Sockets · Thread · Synchronized · BufferedReader
Web · Java EE · Servlet · JSP
Student Result Portal
Replaced a printout-based grade distribution system — teachers upload CSV result files, students query by roll number, department admin manages the records. Java Servlets handled business logic, JSP rendered the view, JDBC talked to MySQL. Deployed to a shared Apache Tomcat instance and used by the actual department.
The JSP threw a NullPointerException live in front of 30 students during demo day. I fixed it at the podium. That was the day I learned: always validate the null path before you demo anything to anyone.
Java · Servlets · JSP · JDBC · MySQL · Apache Tomcat
OOP · Design Patterns · Java
Banking System — OOP From Scratch
CLI banking application with Savings, Current, and Fixed Deposit account types, fund transfers between accounts, compound interest calculation, and a full transaction ledger. The project where design patterns stopped being textbook concepts: Singleton for the bank registry, Factory for account instantiation, Observer pattern for balance threshold alerts.
My first Singleton was not thread-safe — I discovered that after the fact, not before. My first Factory had six switch cases when two polymorphic classes would have done it. That's how you earn the right to have opinions about clean code.
Java · OOP · Collections · Singleton · Factory · Observer Pattern
Game Dev · Java Swing · Algorithms
Tetris — Game Loop from Scratch
Full Tetris in Java Swing — all 7 tetrominoes with proper SRS rotation, wall kicks, ghost piece projection, line-clear with row collapse, progressive speed curve across levels, and a persistent high score table. No game engine, no physics library. Just a fixed-interval game loop, a 10×20 integer grid, and rotation matrices I worked out on graph paper.
Rotation seemed trivial until I realized each tetromino rotates around a different pivot. The I-piece broke three separate implementations. Graph paper, not Stack Overflow, is what finally fixed it.
Java · Swing · 2D Graphics · javax.swing.Timer · Rotation Matrices · Game Loop
Game Dev · Java Swing · Graph Traversal
Minesweeper — BFS Flood Fill Engine
Classic Minesweeper with the one part most clones get wrong: the recursive reveal. When you click an empty cell it cascades outward through all adjacent empty cells until it hits numbered borders. That cascade is BFS in disguise. Also implemented safe-first-click mine seeding — mines are placed after your first move, guaranteeing you never lose on click one.
My recursive flood fill blew the call stack on 30×30 grids. Rewrote it with an explicit ArrayDeque. First time I truly understood why recursion and iteration are interchangeable — and when the stack size makes that choice for you.
Java · Swing · BFS · ArrayDeque · 2D Array · Event Listeners
